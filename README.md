# Serendipity Sri Lanka Travel Website

A complete tourism website for Sri Lanka with:
- modern public-facing pages
- database-backed destinations, experiences, hotels, and contact inquiries
- an admin panel for content management

## Setup
1. Start Apache and MySQL in XAMPP.
2. Open phpMyAdmin and import the file `db.sql`.
3. Visit `http://localhost/traveller`.

## User access
- Register: `http://localhost/traveller/users/register.php`
- Login: `http://localhost/traveller/users/login.php`

## Admin access
- URL: `http://localhost/traveller/admin/login.php`
- Username: `admin`
- Password: `admin123`

## Database config
The database connection is defined in `config/database.php`.
